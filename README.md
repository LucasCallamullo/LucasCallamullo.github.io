## About

Personal portfolio and technical blog. Built from scratch with Astro, TypeScript, and Tailwind CSS. The goal is to showcase my projects, document my journey, and provide a clean, fast, and accessible experience.

- **Stack:** Astro · TypeScript · Tailwind CSS
- **Deploy:** GitHub Pages · GitHub Actions
- **Languages:** Spanish and English (custom i18n)
