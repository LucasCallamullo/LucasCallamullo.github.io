## Sobre este repositorio

Este repositorio contiene el **código fuente de mi portafolio de desarrollador**. Construido como una **aplicación de una sola página (SPA)** con JavaScript, CSS y HTML puro. Muestra mis proyectos de backend, habilidades técnicas y experiencia construyendo aplicaciones reales.
